## 四、专业课备考经验（按学期）

下面是我的个人体验，和任课老师、培养方案有关系，仅供参考。

### 4.1 大一上

#### 数学分析（上）— 洪倩颖老师

- 难度整体可控，重点是先适应数学语言和证明写法。
- 想拿高分：习题册尽量完整做完，并把错题归档。
- 目标稳过：按老师给的范围把基础过扎实，一般没问题。

#### C 语言 — 张莹老师

- PTA 基础题要吃透，后面上机更省力。
- 附加题能练思路，但别把 AI 代码当答案。
- 期末是上机考试，最后拼的是独立编码能力。

#### 力学 — 夏岩 / 施志成 / 曾永志老师

- 以基础内容为主，把课堂反复强调的题型做熟。
- 考前回看高频原题和同构题，提分效率很高。

#### 解析几何 — 江良平老师

- 课程不算难，主要看计算规范和步骤完整性。
- 平时作业按时做，期末基本能覆盖主要得分点。

#### 高等代数（上）— 叶从峰老师

- 讲课节奏清楚，建议尽量保证听课质量。
- 高代基础会影响后续很多课，线性映射和矩阵理论要尽早打牢。
- 考前按范围做专题训练，及格和提分都会更稳。

### 4.2 大一下

#### 高等代数（下）— 叶从峰老师

- 延续上学期方法：课上理解，课后整理。
- 把“定义—定理—例题”串成闭环，不建议只刷题。

#### 数学分析（中）— 洪倩颖老师

- 复习可以沿用数分（上）的思路：概念和证明并重。
- 建一个易错点清单，能少掉很多重复失分。

#### 热学 — 张晓岚老师

- 不建议缺课，课堂和 PPT 信息密度都比较高。
- 点名和课堂参与会影响总评，出勤尽量稳定。

#### 军事理论 — 李潇潇老师

- 按题库系统复习就够用。
- 想冲 85+，题库至少完整过一遍并复查错题。

### 4.3 大二上

#### 数学分析（下）— 苏延辉老师

- 重点放在级数、函数项级数和一致收敛。
- 这些内容是后续分析课的基础，建议先求理解再求速度。

#### 电磁学 — 钟志荣老师

- 跟着课堂走，老师讲得比较清楚。
- 配合 FZU 历年卷复习很有效，老题同构率不低。

#### 模拟电路 — 徐金英老师

- 课程有门槛，建议围绕“电路分析 + 放大器”来复习。
- 期末统考里，PPT 和教材习题的覆盖率通常比较高。

#### 马克思主义基本原理 — 陶火生老师

- 想拿高分，课堂参与要主动一点。
- 期末按范围系统背诵，投入产出比不错。

### 4.4 大二下（方向分流阶段）

> 这个阶段开始分流。我选的是数学方向，所以修了实变函数。

#### 实变函数 — 严锴老师

- 一切尽在不言中

#### 常微分方程 — 邹长武老师

- 整体可控，关键是常见模型和解法模板的熟练度。
- 平时分很关键，尽量别迟到，也别在课上分心。

#### 数字电路 — 张雅珍老师

- 建议以 PPT 和教材习题为主线。
- 真值表、时序分析和典型电路题要练到看到题就能判型。

#### 数学物理方法 A — 林立华老师

- 课堂互动有加分空间，可以主动回答问题。
- 复习时多看“方法在什么条件下能用”，不只背公式。

#### 光学 — 吴怀志老师

- 重点是典型衍射/干涉模型和常见推导流程。

### 4.5 一点总建议

大三之后，课程更看重理解深度和系统能力。临时突击还能救急，但收益会越来越有限。

## 九、给学弟学妹的四点建议

1. **早点规划**：项目和竞赛尽量从大二就开始铺，不要全压在大三。
2. **留下沉淀**：每门核心课都留一份自己的总结，后面联动复习很好用。
3. **练表达**：材料里别只列经历，要讲清楚你怎么想、怎么做、为什么这么做。
4. **稳住心态**：被拒很常见，不要用一次结果否定长期投入。

如果这份资料能帮你少踩几个坑，那它就有价值。祝你顺利。
