# 福州大学本科毕业设计（论文）LaTeX 材料模板开源版

这是一个面向福州大学本科毕业设计（论文）相关材料的 LaTeX 模板发布包。当前目录只保留空白可复用模板、编译配置和必要资源，不包含任何个人论文内容、教师评语、项目专属正文、实验数据或构建产物。

## 目录结构

- `任务书模板`
- `开题报告模板`
- `中期检查表模板`
- `文献综述模板`
- `论文模板`

每个目录都可以单独拿出去编译，不依赖本目录之外的资源。

## 统一编译方式

进入任意模板目录后执行：

```bash
latexmk -xelatex -shell-escape -interaction=nonstopmode -halt-on-error main.tex
```

若需要清理中间文件，可执行：

```bash
latexmk -C
```

## 各模板如何填写

### 任务书模板

- 主入口：`任务书模板/main.tex`
- 先填写顶部“基本信息”里的题目、姓名、学号、学院、专业、年级、指导教师、起止日期。
- 再填写 `设计任务内容`、`主要内容`、`主要参考文献` 三个长文本宏。
- `过程指导记录` 需要按实际指导情况逐行填写时间与内容。

### 开题报告模板

- 主入口：`开题报告模板/main.tex`
- 先填写顶部信息宏：姓名、学号、专业、题目。
- 报告正文按 1 到 7 项填写，分别对应课题来源与意义、研究现状、主要研究内容、研究方案与进度、已具备条件、可能问题与措施、参考文献。
- `指导教师评语` 和签字日期通常由教师填写。

### 中期检查表模板

- 主入口：`中期检查表模板/main.tex`
- 先填写届次、姓名、学号、专业、学院、题目。
- 再填写 `进展情况内容`、`主要存在的问题`、`工作建议`。
- 勾选框由宏控制，默认全部为空白；需要打勾时，把对应宏改成 `\FZUCheckboxChecked`。
- 签字和日期区域按实际提交情况填写。

### 文献综述模板

- 主入口：`文献综述模板/main.tex`
- 先填写封面信息和日期。
- 再填写摘要、关键词，以及七个正文部分。
- 参考文献页默认保留了一个说明条目，正式提交前请全部替换为真实参考文献。

### 论文模板

- 主入口：`论文模板/main.tex`
- 封面信息填写在 `论文模板/sections/frontcover.tex`
- 摘要填写在 `论文模板/sections/00_abstract.tex`
- 正文章节填写在 `论文模板/sections/01_intro.tex` 到 `论文模板/sections/06_conclusion.tex`
- 致谢填写在 `论文模板/sections/acknowledgements.tex`
- 参考文献库在 `论文模板/bib/note.bib`

## 使用建议

- 先只改顶部宏和对应章节入口，不要一开始改样式文件。
- 如果学校当年表格有细微调整，优先改各模板目录下的 `main.tex` 或公共宏文件，不建议跨目录共用资源。
- 正式提交前，建议全文搜索一次占位词，例如“此处填写”“关键词1”“placeholder”，确保空白提示都已替换。
