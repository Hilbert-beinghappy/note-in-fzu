# 文献综述模板

## 编译

```bash
latexmk -xelatex -shell-escape -interaction=nonstopmode -halt-on-error main.tex
```

## 填写入口

- 编辑 `main.tex` 顶部“基本信息”区域。
- 摘要和关键词在 `\摘要内容`、`\关键词内容`。
- 正文按七个部分分别填写。
- 参考文献页在文件末尾，正式提交前请把说明条目替换为真实文献。

## 正文建议

- 研究背景：说明课题价值和综述目的。
- 相关研究方向一到三：按你的课题改成更贴切的小节标题，分别综述不同研究脉络。
- 应用或系统相关研究：可写系统、平台、工程实现或应用研究。
- 现有研究不足与本文定位：归纳不足并引出你的论文定位。
- 小结：总结综述结论并衔接后续论文工作。
