# 任务书模板

## 编译

```bash
latexmk -xelatex -shell-escape -interaction=nonstopmode -halt-on-error main.tex
```

## 填写入口

- 编辑 `main.tex` 顶部“基本信息”区域。
- `\题目`、`\姓名`、`\学号`、`\学院`、`\专业`、`\年级`、`\指导教师` 用于封面信息。
- `\开始年` 到 `\结束日` 用于封面日期区间。
- `\设计任务内容` 用于“设计（论文）任务”整页内容。
- `\主要内容` 用于“毕业设计（论文）的主要内容”整页内容。
- `\主要参考文献` 用于“主要参考文献”整页内容。

## 填写建议

- `设计任务内容` 建议写原始数据、技术要求、进度安排、工作要求。
- `主要内容` 建议写研究对象、核心任务、方法路线、系统实现或实验安排。
- `过程指导记录` 请按真实指导时间逐行补充，不建议保留空表提交。
