# 开题报告模板

## 编译

```bash
latexmk -xelatex -shell-escape -interaction=nonstopmode -halt-on-error main.tex
```

## 填写入口

- 编辑 `main.tex` 顶部“基本信息”区域。
- 正文按 1 到 7 项直接替换对应提示文本。
- `指导教师评语` 与下方签字日期通常由教师填写。

## 每一项通常写什么

- 第 1 项：课题来源、研究背景、研究目的和意义。
- 第 2 项：国内外研究现状、代表性工作与不足分析。
- 第 3 项：论文准备完成的主要研究内容。
- 第 4 项：研究方案、技术路线、进度安排、预期目标。
- 第 5 项：已具备条件与仍需补充的资源。
- 第 6 项：可能遇到的问题与解决措施。
- 第 7 项：主要参考文献。
